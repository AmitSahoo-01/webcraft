WEBCRAFT - A multi-AI agent system for creating websites and web applications.where multiple ai models works together to generate code, design, and content for web development projects. This system leverages the strengths of various AI models to streamline the process of building websites and web applications, making it easier for developers to create high-quality digital products efficiently.


For now its only build for the front-end of the web applications, but in future it will also support back-end development. The system is designed to be user-friendly, allowing developers to input their requirements and receive a complete web application with minimal effort.

It can take input from the user in the form of text prompts, sketches, or even existing code snippets. The AI agents will then collaborate to generate the necessary HTML, CSS, JavaScript, and other front-end technologies to bring the user's vision to life.
